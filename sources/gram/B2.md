## 1. Le discours rapporté (*reported speech*)

On recule d'un temps quand le verbe introducteur est au passé (*said, told, asked, explained*).

| Discours direct | Discours rapporté |
| :--- | :--- |
| présent simple : "I **work** here." | prétérit : She said she **worked** there. |
| présent continu : "I **am working**." | past continuous : She said she **was working**. |
| prétérit : "I **sent** it." | past perfect : She said she **had sent** it. |
| present perfect : "I **have finished**." | past perfect : She said she **had finished**. |
| will : "I **will** call." | would : She said she **would** call. |
| can : "I **can** help." | could : She said she **could** help. |
| must : "You **must** wait." | had to : She said I **had to** wait. |

**Changements de repères :** now → *then* ; today → *that day* ; tomorrow → *the next day* ; yesterday → *the day before* ; here → *there* ; this → *that*.

**Questions :** pas d'inversion. *"Where is the room?"* → *He asked where the room was.* Questions oui / non : *if / whether*. **Ordres :** *told me to + base* (*She told me to wait*).

**Verbes de report utiles :** suggest (-ing ou that), promise, admit, deny, warn, insist, explain, announce.

## 2. Les conditionnels : type 3 et conditionnels mixtes

| Type | Structure | Exemple |
| :--- | :--- | :--- |
| 3 (passé irréel) | If + **past perfect**, **would have** + participe | If we had left earlier, we would have caught the train. |
| mixte | If + past perfect, **would** + base | If I had studied, I would have a better job now. |
| inversion (formel) | **Had** + sujet + participe, ... | **Had we known**, we would have called. |

**Autres formules :** *unless* (à moins que), *provided / providing that* (à condition que), *as long as*, *in case* (au cas où).

**Wish / if only :** *I wish I **had** more time.* (présent, prétérit) ; *I wish I **had known**.* (regret passé) ; *I wish he **would** stop.* (agacement).

## 3. Le passif avancé et la forme causative

| Structure | Exemple |
| :--- | :--- |
| passif avec modal | The report **must be submitted** by Friday. |
| passif à l'infinitif | He expects **to be promoted**. |
| passif impersonnel | It **is said / believed** that the firm is closing. |
| *have / get* + objet + participe | We **had the contract checked** by a lawyer. |

La forme causative sert à dire qu'on **fait faire** quelque chose par quelqu'un.

## 4. Les temps du futur et leurs nuances

| Temps | Structure | Exemple |
| :--- | :--- | :--- |
| future continuous | will + be + -ing | This time tomorrow, I will be flying to Berlin. |
| future perfect | will + have + participe | By June, we will have hired ten people. |
| *be due to* | prévu officiellement | The shipment is due to arrive on Friday. |
| *be about to* | imminent | The meeting is about to begin. |

## 5. Gérondif et infinitif : changements de sens

| Verbe | + -ing | + to |
| :--- | :--- | :--- |
| remember | se souvenir d'avoir fait : *I remember sending it.* | penser à faire : *Remember to send it.* |
| stop | arrêter de : *He stopped smoking.* | s'arrêter pour : *He stopped to smoke.* |
| try | essayer (tester) : *Try restarting it.* | tenter : *I tried to open it.* |
| forget | oublier d'avoir fait | oublier de faire |
| regret | regretter d'avoir fait | regretter d'annoncer : *We regret to inform you ...* |

**Verbes suivis d'un nom ou -ing :** look forward to, be used to, object to, in addition to (la préposition *to* suivie de -ing).

## 6. *So, such, too, enough*

| Mot | Structure | Exemple |
| :--- | :--- | :--- |
| so | so + adjectif / adverbe | The test was so long. |
| such | such + (a) + adjectif + nom | It was such a long test. |
| too | too + adjectif (excès négatif) | It is too expensive. |
| enough | adjectif + enough / enough + nom | It isn't big enough. We have enough chairs. |

## 7. Connecteurs logiques (partie 6 du TOEIC)

| Idée | Connecteurs |
| :--- | :--- |
| addition | moreover, furthermore, in addition, besides |
| opposition | however, nevertheless, on the other hand, whereas, while, although, in contrast |
| cause | because of, owing to, due to, as, since |
| conséquence | therefore, consequently, as a result, thus, hence |
| but | in order to, so as to, so that |
| exemple | for instance, for example, such as |
| conclusion | in conclusion, to sum up, overall |
| temps | meanwhile, afterwards, previously, subsequently |

**Attention :** *because of / due to* + nom ; *because* + proposition. *In spite of / despite* + nom ou -ing.

## 8. Verbes + prépositions

| Verbe | Préposition | Exemple |
| :--- | :--- | :--- |
| depend | **on** | It depends on the budget. |
| apologise | **for** | We apologise for the delay. |
| complain | **about** | He complained about the noise. |
| rely | **on** | We rely on our suppliers. |
| comply | **with** | All staff must comply with the rules. |
| result | **in** / **from** | The delay resulted in extra costs. |
| responsible | **for** | She is responsible for sales. |
| interested | **in** | I am interested in the job. |
| capable | **of** | He is capable of leading the team. |

## 9. Sujets à retenir pour le TOEIC

| Piège | Conseil |
| :--- | :--- |
| accord sujet-verbe | *The number of employees **is** ...* ; *A number of employees **are** ...* |
| adjectifs composés | *a two-hour meeting* (pas de -s : l'adjectif composé reste au singulier) |
| pronoms réfléchis | *He did it **himself**.* |
| ordre des adjectifs | opinion, taille, âge, couleur, origine, matière : *a nice small old red Italian leather bag* |
| article | pas d'article avec les noms indénombrables généraux : *Information is useful.* |
