## 1. L'inversion après un adverbe négatif ou restrictif

Pour l'emphase (style formel), on place l'auxiliaire **avant** le sujet.

| Structure | Exemple |
| :--- | :--- |
| Never / Rarely / Seldom + auxiliaire + sujet | **Never have** I seen such a result. |
| Hardly / Scarcely ... when | **Hardly had** we started **when** the alarm rang. |
| No sooner ... than | **No sooner had** she left **than** he arrived. |
| Not only ... but also | **Not only did** they refuse, **but** they also complained. |
| Only after / Only when / Only then | **Only after** the audit **did** we see the error. |
| Under no circumstances | **Under no circumstances should** you share this password. |
| Little / In no way | **Little did** he know. |

**Inversion conditionnelle (formelle) :** *Should you need help, call us.* (= If you should need) ; *Were it not for the delay, ...* ; *Had we known, ...*

## 2. Phrases clivées (*cleft sentences*) : mettre en relief

| Type | Structure | Exemple |
| :--- | :--- | :--- |
| it-cleft | It is / was + élément + that / who ... | **It was the delay that** caused the loss. |
| wh-cleft | What + sujet + verbe + is / was ... | **What worries me is** the budget. |
| all-cleft | All I want is ... | **All I need is** more time. |

## 3. Propositions participes

| Forme | Exemple | Équivalent |
| :--- | :--- | :--- |
| participe présent (actif, simultané) | **Walking** into the room, she smiled. | While she was walking ... |
| participe passé (passif) | **Written** in haste, the report had errors. | Because it was written ... |
| participe passé composé | **Having finished** the audit, they left. | After they had finished ... |
| après une conjonction | **Before leaving**, please sign. | Before you leave ... |

**Règle :** le sujet logique du participe est celui de la proposition principale.

## 4. Subjonctif et formes équivalentes

Après les verbes et adjectifs d'exigence (*insist, demand, recommend, suggest, essential, vital*), on emploie la **base verbale**, sans -s ni auxiliaire de temps :

- *It is essential that he **be** present.* — *We recommend that she **submit** the form.*
- Forme négative : *We suggested that he **not** attend.*
- Variante courante britannique : *should* + base (*We suggested that he should attend*).

**As if / as though / it's time :** *He talks as if he **were** the manager. It's high time we **left**.*

## 5. Modaux du passé (déduction et regret)

| Forme | Sens | Exemple |
| :--- | :--- | :--- |
| must have + participe | certitude (déduction) | He must have missed the train. |
| can't / couldn't have + participe | impossibilité | She can't have sent it : the file is empty. |
| may / might / could have + participe | possibilité | They might have changed the date. |
| should have + participe | reproche, regret | You should have called us. |
| needn't have + participe | geste inutile | We needn't have hurried. |

## 6. Conditionnels : variantes et formules

| Formule | Exemple |
| :--- | :--- |
| *Unless* (si ... ne ... pas) | Unless we hear from them, we will proceed. |
| *Provided / providing (that)* | Provided that you pay on time, there is no penalty. |
| *Supposing / suppose* | Supposing the supplier fails, what is plan B? |
| *But for + nom* | But for your help, we would have failed. |
| *Otherwise* | Reply today; otherwise the offer will lapse. |
| *If it weren't for* | If it weren't for the discount, we wouldn't buy. |

## 7. Registre formel et informel

| Informel | Formel (TOEIC, courrier) |
| :--- | :--- |
| get | obtain, receive |
| buy | purchase |
| ask for | request |
| find out | ascertain |
| enough | sufficient |
| start / end | commence / terminate |
| help | assist |
| need | require |
| about | approximately, concerning |
| so | therefore, consequently |
| but | however, nevertheless |
| *Can you ...?* | *Would you be so kind as to ...?* |

## 8. Verbes à particule et collocations professionnelles

| Verbe | Sens | Exemple |
| :--- | :--- | :--- |
| roll out | déployer | We will roll out the system in May. |
| scale back | réduire | They scaled back the project. |
| carry over | reporter (budget) | Unused funds carry over. |
| follow up | assurer le suivi | I will follow up with the client. |
| phase out | éliminer progressivement | The old model is being phased out. |
| bring forward | avancer (date) | The meeting was brought forward. |
| draw up | rédiger | Please draw up a shortlist. |
| sign off on | valider | The director signed off on the plan. |

**Collocations :** *meet a deadline, reach an agreement, raise concerns, conduct a survey, place an order, make a profit, take responsibility, run a risk.*

## 9. Nuances d'atténuation (*hedging*)

| Fort | Atténué |
| :--- | :--- |
| This is wrong. | This **seems / appears** to be incorrect. |
| It will fail. | It **is likely / bound to** fail. / It **could well** fail. |
| We disagree. | **I'm not entirely convinced that ...** |
| You must change this. | **It might be worth** changing this. |
| The data prove ... | The data **suggest / indicate** ... |

## 10. Pièges à ce niveau

| Piège | Remarque |
| :--- | :--- |
| *Fewer / less ; number / amount* | *a number of people, an amount of money* |
| *Whom* après une préposition | *the person to **whom** I spoke* |
| Accord après *a majority of / the majority of* | *The majority of staff **are** ...* |
| Parallélisme | *We aim to reduce costs, improve quality and **increase** output.* (même forme) |
| Articles avec les noms propres | *the United States, the Netherlands, but France, Lyon* |
