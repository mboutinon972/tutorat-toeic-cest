## 1. Les temps pour un verbe régulier (*to work*)

| Temps | Formation | Exemple |
| :--- | :--- | :--- |
| Présent simple | base (+ s à he/she/it) | I work / she works |
| Présent continu | am / is / are + work**ing** | I am working |
| Prétérit simple | work**ed** | I worked |
| Prétérit continu | was / were + work**ing** | I was working |
| Present perfect | have / has + work**ed** | I have worked |
| Present perfect continu | have / has been + work**ing** | I have been working |
| Past perfect | had + work**ed** | I had worked |
| Futur (will) | will + base | I will work |
| Futur (be going to) | am / is / are going to + base | I am going to work |
| Futur antérieur | will have + work**ed** | I will have worked |
| Conditionnel présent | would + base | I would work |
| Conditionnel passé | would have + work**ed** | I would have worked |
| Passif présent | am / is / are + work**ed** | It is worked |
| Impératif | base | Work! / Don't work! |
