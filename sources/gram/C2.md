Cette fiche sert à viser le maximum : précision, nuance, registre. Le TOEIC ne distingue pas C2 de C1, mais ces points font gagner les dernières questions difficiles.

## 1. Modalité et nuances d'attitude

| Idée | Formules | Exemple |
| :--- | :--- | :--- |
| probabilité forte | is bound to / is sure to / is likely to | The figures are bound to rise. |
| probabilité faible | might well / may conceivably / is unlikely to | The regulator may conceivably object. |
| distance, prudence | seem, appear, tend to, is said to | Costs tend to rise in winter. |
| reproche atténué | might have been wiser to ... | It might have been wiser to wait. |
| volonté, résolution | insist on, be determined to | We are determined to meet the target. |
| obligation formelle | be required to, be obliged to, be bound by | Staff are obliged to comply. |

**Would** peut exprimer l'habitude passée (*She would call every Monday*) et la politesse ou la distance (*I would suggest ...*).

## 2. Inversions avancées et formes littéraires

| Structure | Exemple |
| :--- | :--- |
| Were + sujet + to + base | **Were the regulator to refuse**, we would appeal. |
| Should + sujet + base | **Should the need arise**, contact legal. |
| Had + sujet + participe | **Had it not been for** the audit, the fraud would have continued. |
| So + adjectif + auxiliaire + sujet | **So convincing was** the argument that nobody objected. |
| Such + be + sujet + that | **Such was** the demand that stocks ran out. |
| Adverbe de lieu + verbe + sujet | **On the table lay** the draft. |
| Neither / Nor + auxiliaire + sujet | **Nor did** they consider the risk. |

## 3. Constructions concessives et contrastives

| Structure | Exemple |
| :--- | :--- |
| however + adjectif + sujet + verbe | **However good** the offer, we cannot accept. |
| whatever / whoever / whenever | **Whatever** the cost, we must finish. |
| albeit (bien que) | A small, **albeit** significant, change. |
| adjective / adverb + as + sujet + verbe | **Tired as** he was, he continued. |
| much as, even if, notwithstanding | **Much as** I admire her, I disagree. |
| whereas / while | **Whereas** sales rose, profits fell. |
| be that as it may | **Be that as it may**, the contract stands. |

## 4. Ellipse, substitution, cohérence du discours

| Procédé | Exemple |
| :--- | :--- |
| ellipse du sujet / auxiliaire | She opened the file and (she) read it. |
| *so / not* de substitution | Will they accept? — **I hope so / I hope not.** |
| *do so* | They asked him to resign; he refused to **do so**. |
| *the former / the latter* | Sales and marketing: **the former** grew, **the latter** shrank. |
| nominalisation (style écrit) | *They decided quickly* → *Their **speedy decision** ...* |
| anaphore | **This** (this fact, this trend) **shows** that ... |

## 5. Marqueurs du discours (cohérence d'un texte)

| Fonction | Marqueurs |
| :--- | :--- |
| nuancer | to some extent, by and large, broadly speaking, in many respects |
| renforcer | indeed, in fact, if anything, notably, in particular |
| reformuler | in other words, that is to say, namely |
| conclure / résumer | all things considered, on balance, in sum, ultimately |
| concéder | admittedly, granted, it is true that |
| introduire un point | as regards, with regard to, with respect to, as for |

## 7. Registres et ton (tableau de choix)

| Neutre | Soutenu | Familier |
| :--- | :--- | :--- |
| ask | enquire | quiz |
| tell | inform / notify | let know |
| end | terminate | wrap up |
| show | demonstrate | — |
| try | endeavour | have a go |
| buy | purchase / acquire | pick up |
| a lot of | a considerable amount of | loads of |
| I think | I am of the opinion that | I reckon |

**Ton :** *tactful* (diplomate), *blunt* (franc, direct), *curt* (sec), *deferential* (déférent), *dismissive* (méprisant). Le TOEIC teste surtout la **cohérence du ton** dans un message professionnel.

## 9. Paraphrase : stratégies (partie 7 et exercices de reformulation)

| Stratégie | Original → paraphrase |
| :--- | :--- |
| synonyme | *begin* → *commence* |
| changement de classe grammaticale | *They decided quickly.* → *Their decision was quick.* |
| actif / passif | *The board approved it.* → *It was approved by the board.* |
| négation + contraire | *It is cheap.* → *It is not expensive.* |
| changement de structure | *Although tired, he stayed.* → *Despite being tired, he stayed.* |
| nominalisation | *because prices rose* → *owing to the rise in prices* |

## 10. Points de précision à vérifier

| Point | Exemple |
| :--- | :--- |
| *which / that* après virgule : **which** obligatoire | *The plan, **which** was costly, failed.* |
| accord avec *none of, neither of, either of* | *None of the staff **was / were** ...* (les deux acceptés, *were* plus courant) |
| singulier de *data, criteria, media* | *data are / is*, *criterion / criteria* |
| *each other / one another* | *They support each other.* |
| *whom* en style soutenu | *to whom it may concern* |
| ponctuation du TOEIC | tiret, point-virgule avant *however* : *Sales rose; however, profits fell.* |
