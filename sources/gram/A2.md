## 1. Le prétérit simple (*past simple*) : une action finie dans le passé

| Type | Règle | Exemples |
| :--- | :--- | :--- |
| Verbes réguliers | verbe + **-ed** | work → worked ; arrive → arrived ; study → studied ; stop → stopped |
| Verbes irréguliers | à apprendre (voir le tableau des verbes irréguliers) | go → went ; take → took ; buy → bought |
| *to be* | **was** (I, he, she, it) / **were** (you, we, they) | She was late. They were in Paris. |

| Forme | Structure | Exemple |
| :--- | :--- | :--- |
| Affirmatif | sujet + verbe au prétérit | We booked a room yesterday. |
| Négatif | sujet + **did not (didn't)** + verbe de **base** | We didn't book a room. |
| Question | **Did** + sujet + verbe de **base** ? | Did you book a room? |

**Piège :** après *did / didn't*, le verbe reste à la base (*Did he go?* et non *Did he went?*).

**Marqueurs :** yesterday, last week, two days ago, in 2024, when I was young.

**Prononciation du -ed :** /t/ après un son sourd (worked), /d/ après un son sonore (played), /ɪd/ après t ou d (needed, decided).

## 2. Présent simple ou présent continu ?

| Présent simple | Présent continu |
| :--- | :--- |
| habitude, vérité : *She works in Lyon.* | action en ce moment : *She is working now.* |
| marqueurs : always, usually, every day | marqueurs : now, at the moment, today |

**Verbes d'état** (pas de forme en -ing) : know, like, love, want, need, understand, believe. *I know the answer.* (pas *I am knowing*).

## 3. Exprimer le futur

| Forme | Emploi | Exemple |
| :--- | :--- | :--- |
| **will** + verbe | décision immédiate, promesse, prévision | I'll send you an email this afternoon. |
| **be going to** + verbe | projet décidé, prévision avec indice | We are going to move to a new office. |
| **présent continu** | rendez-vous fixé | I am meeting Ms. Reyes on Wednesday. |

*Will* : négation **won't** (will not). Question : *Will you come?*

## 4. Les modaux (verbes + base, jamais de -s ni de *to*)

| Modal | Sens | Exemple |
| :--- | :--- | :--- |
| can / could | capacité, permission, demande polie | Could you send me the file? |
| must | obligation forte, forte probabilité | You must wear a badge. |
| have to | obligation (externe) | I have to work on Saturday. |
| should | conseil | You should check your email. |
| may / might | possibilité | It might rain. |
| mustn't / don't have to | **interdit** / **pas obligatoire** | You mustn't smoke. / You don't have to come. |

## 5. Comparatifs et superlatifs

| Adjectif | Comparatif | Superlatif |
| :--- | :--- | :--- |
| court (1 syllabe) | + **-er** + than : *fast, faster than* | the + **-est** : *the fastest* |
| se finit en -y | **-ier** : *easy, easier* | **-iest** : *the easiest* |
| long (2 syllabes ou plus) | **more** + adj + than : *more expensive than* | **the most** + adj : *the most expensive* |
| irréguliers | good → **better** ; bad → **worse** ; far → **farther / further** | **the best** ; **the worst** ; **the farthest / furthest** |

Égalité : *as ... as* (*as cheap as*). Infériorité : *less ... than*, *not as ... as*.

## 6. Dénombrable et indénombrable : quantités

| | Dénombrable (pluriel) | Indénombrable |
| :--- | :--- | :--- |
| beaucoup | many, a lot of | much, a lot of |
| un peu | a few | a little |
| presque pas | few | little |
| exemples | chairs, euros, flights | water, money, luggage, information, advice |

**How many** (dénombrable) / **How much** (indénombrable). *Luggage, information, advice, news* ne prennent **jamais de -s** : *a piece of advice*.

## 7. Connecteurs simples

| Idée | Mot | Exemple |
| :--- | :--- | :--- |
| addition | and, also | We sell books and pens. |
| opposition | but, however | I like tea, but I prefer coffee. |
| cause | because | I am late because the train is delayed. |
| conséquence | so | The flight is cancelled, so I stay here. |
| choix | or | Do you want tea or coffee? |
| ordre | first, then, after that, finally | First, I check my email. |

## 8. Prépositions de mouvement et de lieu

*to* (vers), *from* (de), *into* (dans), *out of* (hors de), *through* (à travers), *across* (de l'autre côté), *along* (le long de), *over* (au-dessus), *under* (sous), *up / down*.

**Temps :** *for* + durée (*for two hours*), *since* + point de départ (voir B1), *during* + événement, *until / by* (jusqu'à / avant), *ago* (il y a).

## 9. Questions de politesse (très utiles au TOEIC)

| Situation | Formule |
| :--- | :--- |
| demander | Could you ...? Would you mind ...-ing? Can I have ...? |
| proposer | Shall I ...? Would you like ...? |
| suggérer | Why don't we ...? How about ...-ing? |
| accepter / refuser | Sure, no problem. / I'm afraid I can't. |

## 10. Faux amis à connaître

| Anglais | Sens réel | Ne signifie pas |
| :--- | :--- | :--- |
| actually | en fait | actuellement (= currently) |
| eventually | finalement | éventuellement (= possibly) |
| library | bibliothèque | librairie (= bookshop) |
| sensible | raisonnable | sensible (= sensitive) |
| delay | retard | délai (= deadline) |
| journey | trajet | journée (= day) |
| to attend | assister à | attendre (= to wait for) |
| to resume | reprendre | résumer (= to summarise) |
