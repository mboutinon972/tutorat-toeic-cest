## 1. Le *present perfect* : have / has + participe passé

| Forme | Structure | Exemple |
| :--- | :--- | :--- |
| Affirmatif | sujet + **have / has** + participe | We have booked the hotel. |
| Négatif | have / has + **not** + participe | She hasn't replied yet. |
| Question | **Have / Has** + sujet + participe ? | Have you finished the report? |

**Emplois :**
1. un fait passé **avec un lien avec le présent** (résultat) : *I have lost my badge.* (je ne l'ai pas)
2. une expérience de vie : *Have you ever visited London?*
3. une durée qui continue : *I have worked here **for** three years / **since** 2023.*

**Marqueurs :** ever, never, already, yet, just, recently, so far, for, since.

| *Past simple* | *Present perfect* |
| :--- | :--- |
| passé **fini**, date précise : *I sent it yesterday.* | passé **relié au présent**, pas de date : *I have sent it.* |
| *last week, in 2024, ago* | *already, yet, ever, for, since* |

**For ou since ?** *For* + durée (*for two weeks*) ; *since* + point de départ (*since Monday*).

## 2. *Present perfect continuous*, *past perfect*

| Temps | Structure | Exemple |
| :--- | :--- | :--- |
| present perfect continuous | have / has + **been** + verbe-ing | I have been waiting for an hour. |
| past perfect | **had** + participe (avant un autre événement passé) | The meeting had started when I arrived. |

## 3. Les conditionnels (type 0, 1, 2)

| Type | Structure | Sens | Exemple |
| :--- | :--- | :--- | :--- |
| 0 | If + présent, présent | vérité générale | If you heat ice, it melts. |
| 1 | If + présent, **will** + base | futur possible | If I finish early, I will call you. |
| 2 | If + **prétérit**, **would** + base | hypothèse irréelle ou peu probable | If I had more time, I would learn Spanish. |

**Attention :** pas de *will* après *if* (*If it **rains**, we will stay*). Au type 2, on dit *If I **were** you* (conseil). Alternative : *unless* = *if ... not*.

## 4. La voix passive : be + participe passé

| Temps | Actif | Passif |
| :--- | :--- | :--- |
| présent | They send the invoice. | The invoice **is sent**. |
| prétérit | They sent the invoice. | The invoice **was sent**. |
| present perfect | They have sent the invoice. | The invoice **has been sent**. |
| futur | They will send the invoice. | The invoice **will be sent**. |
| modal | They must send it. | It **must be sent**. |

L'agent se met après **by** (*written by Ms. Lopez*). On utilise le passif quand l'action compte plus que son auteur (annonces, règlements).

## 5. Les pronoms relatifs

| Pronom | Remplace | Exemple |
| :--- | :--- | :--- |
| **who** | une personne (sujet) | The manager who called is away. |
| **which** | une chose | The printer which is broken is old. |
| **that** | personne ou chose (usage courant) | The report that I wrote is ready. |
| **whose** | possession | The man whose car is outside is my boss. |
| **where / when** | lieu / moment | The hotel where we stayed was clean. |

## 6. Gérondif ou infinitif ?

| Après ces verbes | Forme | Exemple |
| :--- | :--- | :--- |
| enjoy, avoid, finish, suggest, mind, consider | **-ing** | We finished writing the report. |
| want, hope, decide, plan, agree, refuse, manage | **to** + base | She decided to resign. |
| like, love, hate, start, begin | les deux | I like working / to work here. |
| après une préposition | **-ing** | interested in learning |

## 7. Formation des mots (partie 5 du TOEIC)

Pour choisir la bonne forme, repérez la **fonction** du mot manquant.

| Nature | Suffixes courants | Exemple (famille de *decide*) |
| :--- | :--- | :--- |
| nom | -tion, -ment, -ness, -ity, -er / -or, -ance | decision, employment, happiness |
| verbe | -ize, -ify, -en | modernize, simplify, widen |
| adjectif | -ful, -less, -able, -ive, -al, -ous | helpful, useful, reliable, decisive |
| adverbe | -ly | carefully, significantly |

**Astuces :** un **adjectif** précède un nom ou suit *be* ; un **adverbe** modifie un verbe, un adjectif ou une phrase ; un **nom** suit un article ou un adjectif possessif.

## 9. Prépositions et connecteurs

| Idée | Mots |
| :--- | :--- |
| opposition | although, even though, despite / in spite of (+ nom ou -ing), however, whereas |
| cause | because (of), due to, since, as |
| conséquence | so, therefore, as a result |
| but | to, in order to, so that |
| condition | if, unless, provided that, as long as |

**Despite / in spite of** + nom ou -ing : *Despite the rain, we left.* **Although** + proposition : *Although it rained, we left.*

## 10. Pièges classiques

| Erreur | Correct |
| :--- | :--- |
| I am here since Monday | I **have been** here since Monday |
| If I will have time | If I **have** time |
| The man which called | The man **who** called |
| He suggested me to go | He suggested **that I go / going** |
| fewer / less | **fewer** + dénombrable (fewer files) ; **less** + indénombrable (less time) |
